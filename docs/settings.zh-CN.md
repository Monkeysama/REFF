# REFF 内置设置与持久化

本文说明 REFF 官方设置插件的配置项、保存位置和恢复规则。

## 产品边界

`reff.settings` 是 REFF Core 自带的官方系统插件，固定显示在左侧第一项。它随正式 Runtime 分发，不属于可选示例，也不依赖 Lua 注册成功。`reff.*` 是保留命名空间，第三方 manifest 不能声明该前缀。

设置页当前包含：中英文切换、四套主题与自定义强调/背景/表面色、背景透明度、窗口圆角、有限网页表面模糊、全局文字比例、鼠标/键盘独立穿透、窗口位置尺寸记录，以及宿主已成功校验的插件 manifest 列表。

语言切换覆盖 Shell、官方设置页、Element Plus 内置文案和 REFF 通用状态。第三方 Isolated Page 不会被自动翻译；使用 REFF 公共 UI 的页面会收到 `reff:preferences`，可跟随主题和语言。插件自身业务翻译仍由插件作者提供。

背景透明度只调整面板表面，文字与控件保持清晰。表面模糊范围为 0–32，使用网页层 `backdrop-filter` 与有限内部磨砂层，不采样或模糊游戏 DX12 后缓冲。文字大小按 80%–140% 的全局比例同步到 Shell、Element Plus 与使用公共偏好令牌的插件页。

## 配置所有权

配置文件位于：

```text
reframework/data/REFF/settings.json
```

文件使用版本化 JSON。原生 Core 负责白名单、类型和范围校验，通过同目录临时文件加原子替换保存；损坏或不支持的配置回退默认值并记录警告。配置不进入 staging/安装清单，重新部署、升级和卸载清单处理不能覆盖用户配置。

设置请求由 CEF Shell 经命名管道交给 REFF.dll，在 IPC 线程处理，不进入 Lua 或 Present 回调。拖动和缩放结束时，窗口线程只更新内存快照，后台服务线程落盘，避免游戏窗口线程执行磁盘 I/O。

## 输入规则

- 鼠标与键盘穿透分别配置，默认关闭。
- F8、Esc、面板移动和尺寸调整始终由 REFF 捕获。
- 文本框或 IME 活动期间键盘始终由 REFF 捕获，避免组合文本同时进入游戏和网页。
- 鼠标穿透开启后，网页和游戏可能同时响应点击或滚轮，这是该模式的明确行为。
- 当前范围仍限定 Wilds、DX12 和键鼠；不据此扩展到 XInput 或其他游戏轮询路径。
- 键盘拦截同时覆盖 Wilds 的 DirectInput 256 键状态快照；若设备 Hook 不可用，启动日志会明确提示并保留窗口消息过滤作为降级路径。

## 窗口恢复

开启记录后，拖动或缩放结束会保存面板矩形及当时的游戏客户区尺寸。下次游戏启动按新旧客户区比例缩放并裁剪到可见范围，覆盖窗口、无边框、全屏和 DPI 变化的基础恢复路径。关闭记录会清除已存几何；恢复默认设置会回到默认居中尺寸。

## 使用说明

1. 设置页固定在左侧第一项，所有示例和第三方插件仍正常切换。
2. 中英文、主题、自定义颜色、透明度、圆角和模糊即时生效，重启游戏后保持。
3. 鼠标、键盘穿透四种组合行为符合规则；输入框中文输入和候选位置无回归。
4. 开启记录后重启游戏恢复位置尺寸；关闭后下次启动恢复默认居中。
5. Reset Scripts 后设置不变，插件列表恢复，设置页仍可操作。
